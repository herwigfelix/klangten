- Added: two-factor sign-in. Codes arrive by Telegram or by text message, and backup codes help when the phone is gone. It is set up in the account settings, and a code is only asked for on a new device. Klango and Klangten share the setting, so both programs ask for the code
- Added: Klangten for Android, as a highly experimental app. It speaks through the Android speech engines, is operated with gestures, and updates itself from the releases on GitHub: after asking, it downloads the new version, checks it and hands it to the Android installer
- Added: a file from the file manager or a YouTube video can be used as your audio avatar. The first two minutes are kept
- Changed: there are only two update channels left. Stable comes from the Klango server, the rolling release channel follows the releases on GitHub. The RC and Beta channels are gone; a setting that still points to one of them now means Stable
- Changed: guests can read, but the user lists, conferences, mentions, following and the blog library are for signed-in accounts
- Changed: conferences ask for the microphone the way each system expects it
- Fixed: long texts are spoken in parts instead of as one huge utterance
