- Added: two-factor sign-in. Codes arrive by Telegram or by text message, and ten backup codes help when the phone is gone. It is set up and managed under My account, Account security, "Manage two-factor"; that is also where you change the method and create new backup codes. A code is only asked for on a new device, and only the ways set up for the account are offered. Klango and Klangten share the setting, so both programs ask for the code
- Changed: "Forgot password" no longer turns two-factor sign-in off; afterwards you sign in with a backup code. The welcome wizard describes two-factor sign-in accordingly
- Fixed: turning two-factor sign-in off with a wrong password still said "deactivated"
- Added: Klangten for Android, as a highly experimental app. It speaks through the Android speech engines, is operated with gestures, and updates itself from the releases on GitHub: after asking, it downloads the new version, checks it and hands it to the Android installer. The settings offer "Check for updates now" for it
- Added (Android): speech engine and voice are separate fields. Every installed engine is offered, the voices of the phone's language come first and carry readable names
- Added (Android): YouTube is in the Media menu next to the media catalogue and looks the same as on the computer
- Added (Android): in the player a two-finger swipe up or down changes the pitch
- Changed (Android): touch devices no longer announce keyboard shortcuts; where it said "press Enter" it now says "double-tap"
- Fixed (Android): Quit closes the app instead of leaving an empty window
- Note (Android): the app is now signed with a permanent key. If you had a test version before, uninstall it once and install again
- Added: an audio file from the file manager or a YouTube video can be used as your audio avatar. The first two minutes are kept
- Added: guests can read: forums, voice posts, attachments and search, as well as the media catalogue and blogs. When the server requires an account, Klangten says "You need to be signed in for this" instead of "Error"
- Changed: user lists, conferences, messages and contacts, mentioning, following, liking, reporting, bookmarks and the blog library are for signed-in accounts and are no longer offered to guests
- Changed: there are only two update channels left. Stable comes from the Klango server, the rolling release channel follows the releases on GitHub. The Auto, RC and Beta channels are gone; a setting that still points to one of them now means Stable
- Changed: conferences ask for the microphone the way each system expects it
- Changed: on first start Klangten picks the language closest to the system language (for example German for Austria); English only when none fits
- Changed: the last visible "Elten" leftovers, for example in badge names and the diagnostic report, now say Klangten
- Removed (Windows): the check for old Elten installations, which could keep asking to delete an Elten folder
- Fixed: long texts are spoken in parts instead of as one huge utterance; reading the licence used to stall the program
