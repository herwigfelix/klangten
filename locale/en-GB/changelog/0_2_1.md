- Added: "What's new" is back, the way Elten 2 had it: one fixed list with new messages, new posts in followed threads and forums, mentions, blog news, new contacts, birthdays, group invitations and updates, each with its count. Enter opens the matching view. The list is on F10 and in the main menu next to the notification history
- Changed: the notification history is on Control+F10 (Command+F10 on macOS), Shift+F10 still opens the context menu. The notifications themselves stay on the main screen
- Added: in voice forums the thread list plays the spoken title of a thread instead of just reading "Voice discussion"
- Added: "Do not disturb" has four levels: off, notifications muted, calls muted and everything muted. It also works while a call is ringing
- Added: sound themes from the catalogue can be listened to before keeping them and are then kept without downloading them again
- Added: the welcome wizard can be finished from any page, with or without the settings chosen so far
- Added: on Windows the invisible interface can read the subject of messages
- Fixed: on Windows YouTube and the whole Files menu were missing because the built-in programs did not load
- Fixed: an unexpected error after start-up no longer closes Klangten. It reports the error and returns to the main window
- Fixed: when several notifications arrive at once, the same sound plays only once
- Fixed: "Mark all as read" in messages no longer crashes, and new messages in the open conversation appear in the right order, without duplicates and with a single sound
- Fixed: a cancelled load in the forum no longer reports an error, and when loading fails the lists and the position are kept. Creating a thread no longer plays the send sound twice
- Fixed: managing blog co-workers and deleting blogs work again, the confirmation after blog mentions can be heard again, and the new follower notification opens the followers of the right blog
- Fixed: the default sound theme can no longer be deleted
- Fixed: saving the settings without changing a device no longer interrupts the conference audio, and the duplicate "Default" microphone no longer appears in the device list
- Fixed: when the update check fails, it is retried after one minute instead of ten
- Fixed: on macOS punctuation is announced when moving by character in text fields, and Control+Command+Q (lock screen) no longer quits Klangten
- Fixed: headers of text fields with accented letters reach the braille display correctly, and when a field changes while it is being read, the cursor no longer jumps to wrong places
- Fixed: the translations of built-in programs no longer change Klangten's own texts, and technical errors while installing a program are shown in a text window
- Many of these fixes come from Elten 3.0.4 and 3.0.5 by Dawid Pieper and were brought over to Klangten
