- This is where Klangten begins. Klangten is a fork of Elten 3 by Dawid Pieper, and from this version on the development is maintained by sixdotsIT. The break with official Elten is complete: Klangten is a separate program, it is not built, released or supported by the Elten developers, and problems with it must never be reported to them.
- Klangten remains free software under the GNU General Public License version 3. The complete source code of this version is published at https://github.com/herwigfelix/klangten, and every modified file names the change as the licence requires.
- Changed: Klangten talks to a Klango server instead of EltenLink; the account, the forums, the messages, the blogs and the sound themes are those of Klango
- Changed: Klangten installs and runs beside an existing Elten. It uses its own program folder, its own settings file, its own log and its own data directory, so both programs can be used on the same computer without disturbing each other
- Changed: the feed is now a Mastodon client. It sits where the feed used to be and speaks to any Mastodon server you sign in to
- Changed: conferences and calls now use TeamConference
- Added: the media catalogue, YouTube, the file manager with the audio encoders, and the machine interface for assistants are part of the program and no longer have to be installed separately
- Added: sound themes from Klango can be used directly. They are converted when they are downloaded
- Added: audio avatars, so a profile can carry a spoken introduction
- Added: an auto updater page in the settings. It switches the automatic search for updates off and chooses where updates come from: the Klango server, or the rolling release channel, which follows the public releases of Klangten on GitHub
- Changed: on macOS an update is a disk image from which Klangten replaces itself; the app and the image are signed with a Developer ID and notarised by Apple
- Changed: everything former Elten premium accounts unlocked, such as writing in Markdown, is simply included
- Removed: premium accounts, payments, auctions and sponsors, and with them the calendar and the tasks. Notifications remain
- Fixed: opening the forum no longer freezes the program for almost a minute, and voice forums are listed again
- Fixed: downloading a sound theme starts right away instead of waiting on a question whose answer was preselected with "No"
- Fixed: on macOS the interface starts in the language of the system instead of falling back to Polish
