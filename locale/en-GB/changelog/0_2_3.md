- Fixed (Windows): NVDA started reading long texts somewhere in the middle, especially with the Klangten add-on installed. Klangten sent the text in parts and every part cancelled the one before; NVDA now receives the whole text at once
- Fixed (Android): the file manager works. It shows the internal storage, the Klangten folder and Downloads, Documents and Music. For files outside the Klangten folder it asks once for access to all files
- Fixed (Android, iOS): copying and pasting files in the file manager
- New (iOS): Klangten is available as an iPhone app through TestFlight
- Changed (Android, iOS): a double tap now does what the space bar does on a keyboard wherever Enter has no action of its own: ticking checkboxes and items in multi-select lists, playing and pausing players and recordings. Forms are no longer saved as a side effect
- New (Android, iOS): a three-finger tap works like the space bar, for instance to play the spoken title of a thread or a file in the file manager
- Changed (Android, iOS): password fields open a password keyboard that hides what is typed and offers no suggestions
